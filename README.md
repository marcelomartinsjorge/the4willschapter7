# As Quatro Vontades · Capítulo VII · A Madrinha — A Mulher Sem Nome · livro interativo

- `index.html` · o livro
- `capitulo7.js` · o roteiro: páginas, escolhas, a Coleção, os dados dos jogos e a tela final, com os textos em par T('português', 'english'); o inglês é o original
- `motor7.js` · o motor: a água, o sal, a frase de ouro, o medalhão do rosto, a Coleção, o "Fechar os olhos", as escolhas, o som, a pontuação e a tela final
- `jogos7.js` · os minijogos: Ouvir, a Tripulação, Abrir a mão, A Morta, O Anzol, A Lâmina e A Ordem
- `livro.css` + `content/cap07/tema.css` · o visual
- `content/cap07/chapter-config.js` · o codex impessoal
- `NOTAS_CAP7.md` · as decisões, os sistemas, o mapa do capítulo e o que falta
- `MIDIAS_CAP7.md` · tudo o que falta gerar (imagens, vídeos, sons, dublagem), com o contexto de cada cena e o prompt
